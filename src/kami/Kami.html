深入 Rust 所有權系統

記憶體管理是系統程式語言的核心戰場。C 把一切交給程式設計師，Java 把一切交給 GC，而 Rust 選擇了第三條路：在編譯期靜態驗證記憶體安全。這不是取捨，而是範式轉移。

Ownership is Rust's most unique feature. 所有權是 Rust 最獨特的特性。

三條基本規則

  • 每個值都有一個擁有者（owner）
  • 同一時間只能有一個擁有者
  • 擁有者離開作用域時，值即被釋放
IMPORTANT核心觀察 所有權規則在編譯期完成檢查，執行期零成本。這是 Rust 與 GC 語言的根本差異。

移動語義示範


fn main() {
    let s1 = String::from("hello");
    let s2 = s1;            // s1 的所有權移動到 s2
    // println!("{}", s1);  // 編譯錯誤：s1 已失效
    println!("{}", s2);
}
WARNING常見誤解 移動（move）不是複製。以為賦值會自動深拷貝是從其他語言帶來的直覺，在 Rust 中必須顯式呼叫 clone()。
CAUTION 使用 unsafe 區塊會繞過借用檢查器，所有安全保證隨之失效，請務必在 code review 中重點檢視。

借用與生命週期

借用檢查器（borrow checker）確保引用永遠有效1。規則很簡單：同一時間可以有多個不可變借用，或一個可變借用，但不能同時存在2。

    實務工作流程

    使用 rustup 安裝工具鏈，完成後按 Ctrl + ` 開啟終端機驗證版本。 

    cargo build
    會執行完整的借用檢查，錯誤訊息包含修正建議。

    遇到 E0382（value moved）時，優先考慮借用而非 clone。
